# CodeXPets

CodeXPets 是一个无需安装的 Windows 桌面宠物，通过任务栏通知区域图标和云朵气泡显示本地 Codex CLI / Codex 桌面端会话的任务状态。

## 状态

- **空闲**：绿色圆点。
- **进行中**：黄色圆点，带呼吸效果。
- **异常**：红色圆点，例如任务中断、服务端错误、请求失败或异常完成。
- **完成**：短暂显示绿色对勾圆点，并可播放内嵌提示音。

桌面助手会自动换行和滚动较长的任务标题；有多个进行中任务时会顺序轮换显示。

## 使用

1. 双击 `CodeXPets.exe`。
2. 程序会常驻 Windows 任务栏通知区域。
3. 右键托盘图标可显示或隐藏桌面助手、调整设置、查看诊断信息、打开会话目录、查看更新或退出。
4. 如果需要快捷方式，可以运行 `create-shortcuts.ps1`，它会创建开始菜单和桌面快捷方式。

程序是便携式单文件 EXE，不会修改 Codex 会话内容。

## 下载

请从 GitHub Releases 下载最新正式版：

- `CodeXPets-v2.2.1-win-portable.zip`：推荐，解压后直接运行。
- `CodeXPets.exe`：单独的主程序文件。

当前正式版本：**2.2.1**。

## 设置

托盘菜单中的“设置…”支持调整：

- 吸附位置附近的边缘触发区高度。
- 吸附后自动隐藏时间；设为 `0` 表示不自动隐藏。
- 鼠标唤出后的保持时间。
- 任务变化时思考云朵的保持时间。
- 开始、完成和异常语音提醒。
- Codex 会话目录，可用于自定义 `CODEX_HOME` 或桌面端实际使用的本地会话目录。

设置保存在当前 Windows 用户的注册表 `HKCU\Software\CodeXPets` 下。

## 桌面宠物与吸附

桌面宠物固定为黑耳白猫。拖动小猫靠近当前屏幕左侧或右侧边缘并松开，即可切换为对应方向的扒边姿势；顶部不支持吸附。

程序会记住普通位置、所在显示器、吸附方向和垂直位置，并在分辨率或显示器变化后将宠物安全限制在当前工作区域内。未吸附时，小猫会根据所在屏幕的左右半区自动转向屏幕内部。

吸附状态连续一段时间没有任务变化后，小猫会滑出隐藏。隐藏后仅在**最后吸附高度附近的一段固定高度局部边缘**触发滑入，不会因鼠标经过整条屏幕边缘而误唤出。触发后即使鼠标离开，也会继续显示设置中指定的时间。再次拖动猫头可解除吸附。

## 会话监测

默认读取：

```text
%USERPROFILE%\.codex\sessions
```

如果设置了 `CODEX_HOME`，默认读取 `%CODEX_HOME%\sessions`。也可以在“设置…”里手动选择其他目录。

监测器会：

- 持续读取新增的 JSONL 会话内容。
- 支持 UTF-8 中文或 emoji 跨读取块的情况。
- 定期扫描最近修改的旧日期会话，避免漏掉持续多天的任务。
- 根据会话文件活动时间清理失联任务，不依赖固定的 `codex.exe` 进程名。
- 识别任务开始、完成、中断、常见失败和计划进度更新。

## 诊断

如果桌面端任务没有触发状态变化，可从托盘菜单打开“诊断信息…”。诊断窗口会显示：

- 当前监听目录及目录是否存在。
- 已跟踪文件数和活跃任务数。
- 最近扫描、读取和事件时间。
- 最近读取的会话文件。
- JSON 解析错误、文件读取错误和过期任务清理计数。

诊断内容可以直接复制，便于排查不同 Codex 版本的会话格式差异。

## 性能

桌面动画以约 30 FPS 更新，托盘状态和文本布局采用较低频率刷新；空闲时不会再以 60 FPS 重复创建状态列表和执行布局检查。

## 构建

在 Windows PowerShell 中运行：

```powershell
.\build.ps1
```

构建输出：

- `CodeXPets.exe`：主程序。
- `CodeXPets.SelfTest.exe`：自测程序。

执行自测：

```powershell
.\CodeXPets.SelfTest.exe
```

生成便携发布包和 SHA-256 校验文件：

```powershell
.\package.ps1
```

输出位于 `dist` 目录。
